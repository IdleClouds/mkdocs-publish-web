# 第一讲  速算与巧算（加减）

## 核心技巧1：凑整法
1、加法凑整：先凑十/百

2、减法凑整：找个位相同的数

3、添括号巧算：连减时，把后面两个减数相加凑整

4、加补凑整：遇到多个9  1999+199+19

5、基准数：多个数相差不大  276+285+281+282+277


## 核心技巧2：带符号搬家
加减法混合运算时，数字要带着前面的符号一起移动，把能凑整的放一起先算

## 进阶技巧3：分组凑整
遇到多个数加减，分组凑整更高效
